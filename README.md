# Project Estimator

AI-powered project requirement estimator built with **Laravel** and **Vue 3**. Upload a PDF containing client requirements and get back an itemized development budget — feature by feature, with hours, complexity, and cost — generated by an LLM via OpenRouter.

## What it does

1. Upload a requirements PDF (e.g. a client's spec document).
2. The backend extracts the raw text from the PDF.
3. The extracted text is sent to an LLM (configurable model via OpenRouter) with a structured prompt that breaks requirements into discrete features.
4. The LLM returns a JSON breakdown: feature name, category (frontend/backend/fullstack), complexity, estimated hours, and cost.
5. The result is stored and rendered as an itemized budget report in the dashboard, with any ambiguous requirements flagged for human review before the estimate is finalized.

## Tech stack

- **Backend:** Laravel 11, queued jobs for async processing
- **Frontend:** Vue 3 (Composition API), Inertia.js, Tailwind CSS
- **PDF parsing:** [smalot/pdfparser](https://github.com/smalot/pdfparser)
- **LLM provider:** [OpenRouter](https://openrouter.ai) (model-agnostic — swap models via `.env`, no code changes)
- **Database:** MySQL / PostgreSQL

## Features

- 📄 Drag-and-drop PDF upload with validation
- 🤖 Automatic feature extraction and effort estimation from unstructured requirements text
- 💰 Itemized budget breakdown (hours + cost per feature, grouped by category)
- ⚠️ Flags ambiguous or underspecified requirements that need clarification before final budgeting
- 📊 Dashboard with past estimates, status tracking, and hours-by-category visualization
- 🔁 Configurable hourly rate and LLM model per project

## Getting started

```bash
git clone https://github.com/your-username/project-estimator.git
cd project-estimator

composer install
npm install

cp .env.example .env
php artisan key:generate
```

Set your OpenRouter credentials in `.env`:

```env
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxxxx
OPENROUTER_MODEL=anthropic/claude-sonnet-4.5
```

Run migrations and start the app:

```bash
php artisan migrate
php artisan queue:work
npm run dev
php artisan serve
```

## How estimation works

The extracted PDF text is sent to the LLM with a prompt instructing it to return strict JSON: a list of features (each with category, complexity, hours, and cost) plus a total. See [`app/Services/BudgetEstimationService.php`](app/Services/BudgetEstimationService.php) for the prompt template and response parsing.
